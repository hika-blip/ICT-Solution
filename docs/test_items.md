# ひたふら テスト項目一覧

対象: ひたふら（日立市付近の歩行者向け経路案内・避難支援アプリ）。
危険個所の投稿、通行不可・細道を避ける経路案内、緊急時モードを含む。

全 81 項目（優先度「高」39、「中」35、「低」7）。
同じ内容のチェック表を `test_items.xlsx` に用意している（結果の記入・集計はExcelで行う）。

## テスト前の準備

- 一般ユーザーを2名以上（他人のデータの確認用）と、管理者アカウントを用意する。
- `data/map.graphml`（標高入り）と、`road_widths.json`（リポジトリ直下）を用意する。確認は `python scripts/setup_data.py --check`。
- スマホ表示（Chromeのデバイスツールバー）と、現在地が取れない状態（位置情報を許可しない）も試す。
- 危険個所・ピンのテストデータは、確認後に削除する。

## 特に重点的に確認する点

1. 避難経路が出ない地点がないか（細道・通行不可の除外で経路が見つからない場合の案内も含む）
2. 画面と探索の一致（縞線の道を、実際の経路が通らないか）
3. 権限まわり（他人のデータを参照・削除できないか）

優先度: **高** = アプリの根幹・安全に関わる / **中** = 通常の機能 / **低** = あれば望ましい
